# 校园时间簿｜课程实践项目

这是一个**已经完整可运行但完全不包含 AI 组件**的 Flask 时间轴项目

今天的任务是：在这个项目中添加“直接用 AI 识别日常通知”的能力，将**类似以下的通知**转换为**对应事项**，并直接显示在时间轴上

```txt
【考试通知】
期中考试时间为明天晚上6点至8点，共2个小时，地点在教一1102和1602。
由于三个班共用两个考场，所以您需要对照图片确认自己所在的考场。如果您在表格中找不到自己，请及时联系助教！
祝大家考试顺利！
```



## 已实现功能

- 手动创建、编辑和删除事项
- 开始时间、结束时间均可单独留空
- 高 / 中 / 低优先级
- 手动完成与恢复待办
- 按真实时间分为：即将发生、正在进行、时间待确认、已完成 / 已结束
- 标题、地点和备注搜索
- 优先级筛选
- 时间轴与交互日历视图
- 点击日历日期后，可直接在该日新建事项
- 已经填入的事件持久化保存



## 课上实践步骤

- **尝试启动已有的项目**

  - Windows

    ```powershell
    # 先 cd 项目对应的路径，并且确保你的 python 已经安装
    python -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe app.py
    ```

  - macOS / Linux

    ```bash
    # 先 cd 项目对应的路径，并且确保你的 python 已经安装
    python3 -m venv .venv
    ./.venv/bin/python -m pip install -r requirements.txt
    ./.venv/bin/python app.py
    ```

  - 若没有相关的报错，运行完毕后浏览器打开：`http://127.0.0.1:5000` 即可访问使用

- **让 AI 能够从日常通知语言中识别标题、起止时间、地点和备注相关信息**

  - 能够让 ai 参与到具体的分析过程中
  - 确保 ai 能够遵循项目中的相关规整来帮我们进行对应的构建与分析

- **填入我们自己的 api key**

  - 成功获取到自己的 api key
  - 能够在本地使用自己的 api key 使用大语言模型服务
  - 真实使用场景测试：ai 分析的功能在前端能够合理被调用，实现预期效果
  - 保存好我们的 api key
