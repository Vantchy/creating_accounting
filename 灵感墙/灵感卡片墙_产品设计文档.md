# 灵感卡片墙 — 产品设计文档

## 1. 产品概述

一款纯前端（HTML/CSS/JS 单页）的灵感记录与展示工具。用户随手记录灵感、好句、语录，在沉浸式全屏页面中以**横向传送带**形式自动滚动展示，鼠标悬停暂停，点击查看完整内容。

---

## 2. 核心功能

### 2.1 卡片管理（CRUD）

| 功能 | 说明 |
|------|------|
| **新建卡片** | 填写标题、正文、来源，自定义背景色（纯色或渐变），保存后加入卡片墙 |
| **编辑卡片** | 点击卡片 → 模态框查看详情 → 可进入编辑模式修改内容 |
| **删除卡片** | 在模态框详情中提供删除按钮，**二次确认弹窗**确认后才执行删除 |
| 数据字段 | 标题（必填）、正文（必填）、来源（选填）、背景色配置（存储为 CSS 值） |

### 2.2 卡片展示

- **布局**：全屏沉浸式，卡片排成单行，在视口内水平无限循环滚动
- **卡片尺寸**：固定宽高，所有卡片尺寸统一，视觉整齐
- **悬停暂停**：鼠标悬停在任何卡片上时，滚动暂停
- **点击查看**：点击卡片弹出模态框，展示完整标题、正文、来源
- **自动滚动**：页面加载后自动开始滚动，方向从左到右或从右到左（可配置）

### 2.3 搜索与高亮

- 搜索范围：同时匹配**标题**和**正文**
- 输入关键词后实时过滤，仅显示匹配的卡片
- 匹配到的关键词在卡片标题和正文中**高亮显示**
- 搜索状态下自动滚动暂停，退出搜索后恢复

### 2.4 数据持久化

- 使用浏览器 `localStorage` 存储所有卡片数据
- 无需后端，无需导入导出功能

## 3. 交互流程

### 主界面
```
┌─────────────────────────────────────────────────┐
│  [灵感卡片墙 标题]          [搜索框]  [新建按钮] │
│                                                   │
│  ← 卡片1 │ 卡片2 │ 卡片3 │ 卡片4 │ 卡片5 →       │
│     (自动水平滚动中...)                           │
│                                                   │
│  鼠标悬停 → 暂停滚动                              │
│  点击卡片 → 弹窗查看详情                          │
└─────────────────────────────────────────────────┘
```

### 新建/编辑流程
1. 点击"新建"按钮 → 弹出表单模态框
2. 填写标题、正文、来源
3. 选择背景色（拾色器或预设色板）
4. 保存 → 卡片插入墙中
5. 编辑：在详情模态框中点击"编辑" → 同表单模态框，预填原数据

### 删除流程
1. 在详情模态框中点击"删除"
2. 弹出二次确认弹窗："确定要删除这张卡片吗？"
3. 确认 → 删除卡片；取消 → 关闭确认弹窗

## 4. 视觉风格

### 4.1 整体风格

- **深色主题**：背景深色（如 `#0f0f1a` 级别）
- **玻璃质感（Glassmorphism）**：
  - 卡片背景：半透明毛玻璃效果（`backdrop-filter: blur()`）
  - 卡片边框：细边框带半透明渐变
  - 轻微阴影 + 发光边缘
  - 避免扁平化，通过层次感、光晕、微动效增强质感

### 4.2 卡片背景色

- 每张卡片可独立设置背景色
- 支持：
  - **纯色**：CSS 颜色值
  - **渐变**：两个颜色 + 角度（如 `linear-gradient(135deg, #667eea, #764ba2)`）
- 交互方式：颜色选择器 + 多组预设色板（方便快速选用）

### 4.3 移动端适配

- 响应式设计，在手机上也保持良好体验
- 触摸滑动代替鼠标悬停（触摸时暂停滚动）
- 模态框在小屏上全屏展示

## 5. 技术方案

| 项目 | 方案 |
|------|------|
| 技术栈 | 纯 HTML + CSS + JavaScript（单页应用） |
| 存储 | `localStorage` |
| 第三方库 | 尽可能不依赖外部库，纯原生实现 |
| 文件结构 | 单 HTML 文件（或 HTML + CSS + JS 分离） |

## 6. 数据模型

```javascript
{
  id: "uuid-string",           // 唯一标识
  title: "灵感标题",            // 必填
  content: "灵感正文内容...",    // 必填
  source: "来源出处",            // 选填
  bgColor: {                    // 背景色配置
    type: "gradient",           // "solid" | "gradient"
    color1: "#667eea",          // 颜色1（纯色时仅用此值）
    color2: "#764ba2",          // 颜色2（渐变时使用）
    angle: 135                  // 渐变角度（渐变时使用）
  },
  createdAt: "2026-08-15T10:00:00.000Z",  // 创建时间
  updatedAt: "2026-08-15T10:00:00.000Z"   // 更新时间
}
```
