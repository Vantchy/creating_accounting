# 前端风格指南

> 本文档记录个人偏好的网页设计风格，可直接作为前端开发参考。

---

## 一、设计理念

**成熟简约的阅读型风格**

- 衬线标题 + 无衬线正文，有文化感但不刻板
- 暖白背景 + 纯白内容区，层次分明
- 线性图标，拒绝卡通和幼稚元素
- 宽松的字间距和行高，阅读舒适
- 胶囊标签 + 居中元信息，信息层级清晰

## 三、排版系统

### 3.1 字体

| 类型 | 字体栈 | 用途 |
|------|--------|------|
| 标题/展示（Display） | "LXGW WenKai", "Noto Serif SC", "Songti SC", "STSong", SimSun, serif | 文章大标题、H2/H3、站点名 |
| 正文（Body） | "Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "LXGW WenKai", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif | 文章正文 |
| UI 无衬线 | -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif | 按钮、标签、导航、表单 |
| 英文/数字 | "Atkinson Hyperlegible", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif | 英文正文、数字 |
| 等宽 | "LXGW WenKai Mono", "Noto Sans Mono CJK SC", "Source Code Pro", Consolas, monospace | 代码块 |

> **偏好**:
> - 标题使用 **霞鹜文楷（LXGW WenKai）**，这是一款中文楷体字体，有文化感和手写温度，但不幼稚不卡通
> - 正文优先衬线体（Noto Serif SC），可读性好，阅读体验佳
> - UI 界面元素使用无衬线体，现代简洁
> - 需引入霞鹜文楷 webfont 或使用 CDN（如 `cdn.jsdelivr.net/npm/lxgw-wenkai-webfont`）

### 3.2 字号层级

| 层级 | 字号 | 字重 | 行高 | 字间距 | 用途 |
|------|------|------|------|--------|------|
| H1 | 2.75rem (44px) | 700 | 1.3 | 0.05em | 文章大标题（居中，衬线体） |
| H2 | 1.875rem (30px) | 600 | 1.4 | 0.03em | 区块标题（如"前言"） |
| H3 | 1.375rem (22px) | 600 | 1.4 | 0.02em | 小标题 |
| H4 | 1.125rem (18px) | 500 | 1.5 | 0.02em | 卡片标题 |
| Display | 1.875rem (30px) | 700 | 1.3 | 0.02em | 用户名、站点名 |
| Body | 1.125rem (18px) | 400 | 1.8 | 0.02em | 正文（偏大，阅读舒适） |
| Small | 0.9375rem (15px) | 400 | 1.6 | 0.01em | 辅助文字、元信息、个性签名 |
| Caption | 0.8125rem (13px) | 400 | 1.5 | 0.02em | 标签文字、日期 |

> **偏好**: 正文字号偏大（18px），行高宽松（1.8），字间距 0.02em，整体阅读体验舒适。标题字间距更宽，显得大气。

### 4.2 圆角

| 名称 | 数值 | 用途 |
|------|------|------|
| none | 0 | 方形 |
| sm | 0.25rem (4px) | 小元素 |
| md | 0.5rem (8px) | 按钮、输入框 |
| lg | 0.75rem (12px) | 卡片 |
| xl | 1rem (16px) | 大卡片、弹窗 |
| full | 9999px | 圆形、胶囊按钮 |

### 4.3 阴影

| 名称 | 值 | 用途 |
|------|----|------|
| sm | `0 1px 2px rgba(33,33,33,0.06)` | 轻微悬浮 |
| md | `0 2px 8px rgba(33,33,33,0.10)` | 卡片默认 |
| lg | `0 8px 24px rgba(33,33,33,0.14)` | 悬浮状态、弹窗 |

### 4.4 文章内容区布局（桌面端）

**容器结构**: 页面背景 `#fafafa` → 白色圆角卡片 → 内部内容区

| 属性 | 值 | 说明 |
|------|----|------|
| 卡片最大宽度 | `860px` | 桌面端文章卡片最大宽度 |
| 卡片水平外边距 | `auto` | 居中 |
| 卡片外边距（上下） | `32px 0` | 与视口顶部/底部间距 |
| 卡片内边距 | `48px 56px` | 桌面端内边距 |
| 文字行宽 | `~748px` | 860 - 56×2，理想阅读宽度 |
| 卡片圆角 | `16px` | 顶部和底部圆角 |
| 卡片背景 | `#ffffff` | 纯白 |
| 卡片边框 | `1px solid #e4e4e4` | 极淡边框（可选） |
| 卡片阴影 | `var(--shadow-lg)` | `0 8px 24px rgba(33,33,33,0.14)` |

> **响应式**: 移动端卡片内边距缩减为 `24px 20px`，卡片圆角可减小为 `12px`，最大宽度 100%。

```css
.article-card {
  max-width: 860px;
  margin: 32px auto;
  padding: 48px 56px;
  background: var(--color-bg);
  border-radius: var(--radius-xl);
  border: 1px solid var(--color-border-soft);
  box-shadow: var(--shadow-lg);
}

@media (max-width: 768px) {
  .article-card {
    margin: 0;
    padding: 32px 20px;
    border-radius: 0;
    border: none;
    box-shadow: none;
  }
}
```

## 六、动效与交互

### 6.1 过渡时长

| 名称 | 时长 | 用途 |
|------|------|------|
| fast | 150ms | 悬停、点击反馈 |
| normal | 250ms | 常规过渡 |
| slow | 400ms | 模态框、展开 |

### 6.2 缓动函数

```css
:root {
  --ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);
  --ease-out: cubic-bezier(0, 0, 0.2, 1);
  --ease-in: cubic-bezier(0.4, 0, 1, 1);
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

### 6.3 交互偏好

**链接引导线滑动效果（Leader Line Hover）**

列表项中标题与日期/辅助信息之间的浅色引导线，在鼠标悬停时：
1. 颜色从浅灰 `#d4d4d4` 过渡到黑色 `#212121`
2. 可配合 `transform: scaleX(1.02)` 产生轻微"滑动延伸"感
3. 过渡时长 **250ms**，缓动 `cubic-bezier(0.4, 0, 0.2, 1)`
4. 效果克制，不夸张，营造精致的交互反馈

```css
.leader-line {
  flex: 1;
  height: 1px;
  background-color: var(--color-accent-gray);
  transform: scaleX(1);
  transform-origin: left center;
  transition: background-color 250ms var(--ease-in-out),
              transform 250ms var(--ease-in-out);
}

.item:hover .leader-line {
  background-color: var(--color-text);
  transform: scaleX(1.02);
}
```

> **原则**: 交互反馈应细腻、克制，用颜色变化和微小位移传达状态，避免大幅动画。
